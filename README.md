# Portfolio

Personal portfolio — a single glass panel over an animated, dithered gradient background.

Built with React, TypeScript and Vite. No UI or animation libraries; the background is a hand-written WebGL2 shader.

## Run

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build into dist/
```

## Features

- **Dithered background** — animated noise gradient + pixel-art landscape, ordered-dithered (Bayer 2–16, gradient noise, threshold) in one fragment pass. The canvas spans the whole document and only redraws the visible band.
- **Frosted glass panel** — backdrop blur + saturation + SVG grain.
- **Themes** — Light / Dark / System, persisted, with a smooth crossfade (registered `@property` tokens + tweened shader colours).
- **Text entry animations** — staggered fade/unblur on scroll; respects `prefers-reduced-motion`.
- **⌘/ (Ctrl+/) settings panel** — live-tune dither, gradient, landscape and glass parameters. "Copy JSON" exports them for use as new defaults.

## Where things live

| Path | What |
| --- | --- |
| `src/theme/themes.ts` | Theme registry — CSS tokens + shader colours per theme. Add a theme here (and its id in the inline script in `index.html`). |
| `src/fx/params.ts` | Default dither / gradient / glass parameters (theme-independent). |
| `src/fx/shader.ts` | GLSL: gradient field, landscape compositing, dithering. |
| `src/fx/DitherRenderer.ts` | WebGL2 wrapper, colour tweening. |
| `src/fx/DitherBackground.tsx`, `DitherFill.tsx` | Page background and small dithered fills (toggle, Copy Mail). |
| `src/pages/Home.tsx` | Page content and sections. |
| `src/content.ts` | Experience, work and link data. |
| `src/components/ConfigPanel.tsx` | The ⌘/ panel. |

## Notes

- Type is **Lekta**: the Lecta typeface (by Gia Bamrud) renamed, with Medium/SemiBold/Bold generated by `scripts/make-weights.py` (FontForge). Lecta's licence allows free use and redistribution; modified versions must use a different name and the same licence, may not be sold, and the font may not be used by/with AI systems. `public/fonts/Lecta.otf` is kept as the source for the script.
- **Fonts are not in this repo** (`public/fonts/` is git-ignored). To run locally, put `Lecta.otf` in `public/fonts/` and generate the weights: `fontforge -lang=py -script scripts/make-weights.py public/fonts/Lecta.otf public/fonts`. Without them the site falls back to a system font.
- Work images are full-size Figma exports; compress before shipping.
